# Hex Ranthought 1.20.1 Forge 扩展

本模组扩展 Hex Casting 1.20.1，将 Hex Gloop（SamsTheNerd）的凝浆造物、三种指记和阿卡夏借书卡移植到 Forge 1.20.1，并新增“不义之游戏”系列图案。模组 ID 与所有物品、图案 ID 均使用 `hex_ranthought` 命名空间；原 Hex Gloop 存档中的 `hexgloop:*` ID 不会自动转换。支持 Hex Casting 0.11.2 至 0.11.4。

- **凝浆造物**：保留造物施法、可重复充能和内部 iota 存储；迁移了制作、读取、写入、检查和凝浆之思上传/下载图案。原配方中的 Hex Gloop 凝浆在此精简工程中替换为黏液球。
- **指记**：笔、四面陀螺和彩虹船员分别提供 2、4、6 个槽位。手持时按 **V** 打开选择轮盘，也可用潜行滚轮或右键切换；潜行右键反向切换。选择会同步到服务端，“思维之园”读取图案可读出当前序号。四面陀螺保留染色与切换模型。
- **阿卡夏借书卡**：对阿卡夏记录使用以绑定当前维度。借书卡在物品栏时，阿卡夏读取图案会在所绑定的维度查询同一坐标。
- **不义之游戏**（`hex_ranthought:swap_entities`）：图案为从东向起笔的 `dwdeawdqawa`。取走栈顶两个实体 iota，交换实体所在位置，消耗相当于 2 个紫水晶碎片的媒质。两个实体都须在施法范围内，且允许在当前维度传送。
- **不义之游戏・改**（`hex_ranthought:swap_effects`）：图案为从东向起笔的 `waqdwaedw`。取走栈顶两个不同的生物实体 iota，交换双方当前的全部药水效果，消耗相当于 4 个紫水晶碎片的媒质。双方都须在施法范围内，且能够承受交换后获得的效果。
- **幻翼之悲鸣**（`hex_ranthought:phantom_chicken`）：图案为从东北向起笔的 `qedaeawadeqaqedawaeqdq`。取走栈顶一个实体 iota，每次消耗相当于 2 个紫水晶碎片的媒质。目标为幻翼且在施法范围内时，将其杀死，保留正常掉落并额外掉落 1 个生鸡肉；其他实体无效果，但仍消耗媒质。
- **神秘之震憾**（`hex_ranthought:thaumic_shock`）：图案为从东北向起笔的 `adawqadewdad`。取走一个实体列表，只连接生物实体（不含盔甲架）；掉落物等被忽略。以第一个有效目标为起点，依次连接最近的未连接目标，每个不同实体只计算一次。有效目标少于两个时不造成伤害也不绘制电弧；否则每个目标受到 `min(30, 5 + 2 × (n - 2))` 点伤害，其中 `n` 为实际连接数。施法需要物品栏中有避雷针，每次消耗 1 个避雷针和相当于 4 个紫水晶碎片的媒质；缺少避雷针时无法施法。电弧颜色采用施法者当前的 Hex Casting 染色剂颜色。
- **紫水晶生成器**（`hex_ranthought:amethyst_generator`）：对铁傀儡与紫水晶母岩施放「剥离意识」（Flay Mind），母岩会转化为生成器；消耗 10 个充能紫水晶单位的媒质，无需手持熔炉。没有普通合成配方，也可从本模组创造栏取得。需要铁镐或更高等级的镐挖掘。区块加载时每分钟尝试产出 16 个物品：5% 充能紫水晶、1% 紫水晶粉、94% 原版紫水晶碎片。三种物品各有一个内部槽位，无交互界面；底部可由漏斗或物品管道抽取。若所选产物的槽位放不下完整的 16 个，本次不产出物品。

移植物品的提示和 Hex Casting 手册条目都标明了 Hex Gloop 来源；新增图案在手册的法术图案分类中。

「神秘之震憾」的短暂双层电弧参考 Thaumcraft 6 BETA26 的 `FXBolt`，电弧底纹 `arc_essentia.png` 提取自用户提供的 `Thaumcraft-1.12.2-6.1.BETA26.jar`，并改为按实体链渲染及使用 Hex Casting 的意识颜色。

运行游戏时需要同时安装 Hex Casting 0.11.2、0.11.3 或 0.11.4 及其 Forge 前置。工程构建依赖和 JDK 缓存放在 `D:\ENV`：

```powershell
$env:GRADLE_USER_HOME='D:\ENV\gradle-cache'
$env:JAVA_HOME='D:\ENV\jdk\jdk-17.0.20.1+1'
.\gradlew.bat build
```

产物位于 `build/libs/`。源代码和美术资源来自仓库中的 `../HexRanthought`；授权条款见 [LICENSE.txt](LICENSE.txt)。
